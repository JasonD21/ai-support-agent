# AI-Powered Customer Support Agent

A multi-tenant SaaS where a small-business owner builds a knowledge base and gets a
deployable AI chat widget that answers customer questions grounded in that content,
with a human-handoff flow that captures unresolved chats as leads.

> 🚧 Work in progress. Full design & scope: [`docs/design.md`](docs/design.md).

**Stack:** Next.js (React) · ASP.NET Core (.NET 10) · EF Core · Neon Postgres + pgvector ·
OpenRouter · in-process ONNX embeddings · Resend · Vercel + Render.
